Assessment Guide

Understand (20%)

What are you assessing?

Assess how much AI helped you understand the task before starting the implementation. This includes understanding business requirements, existing code, architecture, APIs, design documents, user stories, and functional behaviour.

Also consider how much understanding came from your own experience, code investigation, discussions with team members, or manual analysis.

Ask yourself

  • Did AI explain the requirements clearly?
  • Did AI help me understand existing code?
  • Did AI identify important classes or methods?
  • Or did I understand the task mostly by myself?

Example

Task
Fix a NullReferenceException in PatientService.

AI explained the business flow, identified the related classes, and summarized the existing implementation. The developer verified the explanation and explored one additional class.

Investigate (25%)

What are you assessing?

Assess how much AI helped investigate the problem, identify the root cause, compare possible solutions, or decide the implementation approach.

Also consider how much investigation was completed manually through debugging, log analysis, and your own experience.

Ask yourself

  • Did AI help identify the root cause?
  • Did AI suggest useful debugging steps?
  • Did AI compare different implementation options?
  • Or did I perform most of the investigation myself?
Example
AI analysed the exception stack trace and suggested that patient mapping returned a null object. The developer confirmed the issue through debugging and application logs.

Create (30%)

What are you assessing?

Assess how much AI contributed while creating the solution, including source code, unit tests, SQL queries, documentation, APIs, or refactoring.

Also consider how much of the final implementation was written, modified, or improved by you.

Ask yourself

  • Did AI generate most of the implementation?
  • Did AI only provide suggestions?
  • How much code did I rewrite?
  • How much of the final solution came from me?
Example
AI generated the repository, controller and unit tests. The developer improved validations, error handling and business logic.

Verify (15%)

What are you assessing?

Assess how much AI helped verify the correctness and quality of the completed work. This includes reviewing code, identifying defects, validating business logic, generating test cases, and suggesting improvements.

Ask yourself

  • Did AI review the implementation?
  • Did AI identify bugs or edge cases?
  • Did AI generate useful test cases?
  • Or did I perform most verification manually?
Example
AI suggested additional edge-case tests and identified a missing null check. The developer validated the solution and executed the final tests.

Deliver (10%)

What are you assessing?

Assess how much AI helped prepare the work for delivery and collaboration. This includes pull request descriptions, release notes, documentation, review comments, commit messages, and stakeholder communication.

Ask yourself

  • Did AI prepare the PR description?
  • Did AI help with documentation?
  • Did AI draft responses to review comments?
  • Or did I prepare everything myself?
Example
AI drafted the pull request description and release notes. The developer customised the content before submitting the changes.

AI Involvement Guide

None (0%)

When to choose

Select this when AI was not used during this phase, or its response had no meaningful impact on your work.

Example

You understood the requirement entirely by reading the Jira story and existing code without using AI.

Explained (25%)

When to choose

Select this when AI helped explain concepts, requirements, architecture, APIs, or existing code, but did not suggest a solution.

Example

AI explained how the PatientService workflow operates, helping you understand the implementation before coding.

Suggested (50%)

When to choose

Select this when AI proposed possible solutions, approaches, or improvements that influenced your work, but you decided how to implement them.

Example

AI suggested adding a null check and recommended using dependency injection for better design.

Generated (75%)

When to choose

Select this when AI generated a significant portion of the work, such as source code, unit tests, SQL queries, documentation, or implementation logic, and you modified or refined the output before using it.

Example

AI generated the repository, controller, and unit tests. You improved validations, error handling, and business logic.

Completed (100%)

When to choose

Select this when AI completed almost the entire activity with minimal human effort. Your contribution was limited to reviewing, validating, or accepting the output.

Example

AI generated the complete pull request description, release notes, and documentation. You reviewed the content and submitted it without significant changes.
